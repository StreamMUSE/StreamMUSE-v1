# 系统架构说明

## 任务定义

无条件双轨钢琴音乐生成：模型自回归生成完整的旋律+伴奏序列，无需条件输入。

$$P(X) = \prod_{t=1}^{T} P(x_t | x_{<t})$$

## 模块职责

| 模块 | 职责 | 不做什么 |
|------|------|----------|
| `my_tokenizer.py` | 编解码：pianoroll ↔ token，构建训练序列/解析生成序列 | 不做 I/O、不做模型推理 |
| `model.py` | 纯模型推理：接收 initial tokens → 无条件自回归生成 | 不做文件加载、不调 tokenizer |
| `Token2Midi.py` | beats 解码 → MIDI 文件输出 | 不做生成、不知道 model 返回格式 |
| `inference.py` | 编排层：加载数据 → initial tokens → model → 解析 → converter | 唯一涉及全链路的胶水代码 |
| `PianoDataset.py` | 训练数据加载 + 增强 + batching | 不做推理 |
| `config.py` | 所有超参数和 token ID 定义 | — |

## 序列格式

```
[BOS][TS][BPM] [BAR][BEAT][TRK_MEL][mel₀...][TRK_ACC][acc₀...] [BEAT][TRK_MEL][mel₁...][TRK_ACC][acc₁...] ... [BAR]... [EOS]
```

每一拍的结构：`[BEAT] [TRK_MEL] [mel patch tokens] [TRK_ACC] [acc patch tokens]`

### 与旧格式的区别

| 特性 | 旧格式 (实时伴奏) | 新格式 (无条件生成) |
|------|-------------------|---------------------|
| 轨道顺序 | acc 先, mel 后 | **mel 先, acc 后** |
| 轨道标记位置 | 内容末尾 (终止符) | **内容前面 (起始符)** |
| 位置编码 | 稀疏位置 token | **固定音高顺序，无 pitch token** |
| Loss | 选择性 (仅 acc) | **全 token 参与** |
| 推理方式 | Schedule-driven (注入 mel) | **无条件自回归** |

### Token 词表

| ID 范围 | 含义 |
|---------|------|
| 0-80 | patch 三进制编码（$3^4=81$ 种） |
| 81 | empty_patch_marker（空 patch 占位） |
| 170 | track_marker_acc（acc 轨起始） |
| 171 | track_marker_mel（mel 轨起始） |
| 172 | beat_marker |
| 255 | bar_token |
| 256/257/258 | EOS/BOS/PAD |
| 259-263 | 拍号（5 种） |
| 264-267 | BPM 分桶（4 种） |

vocab_size = 268

### 固定展开编码

不再插入 pitch marker，而是把每拍每轨的 88 个音高位按固定顺序依次展开：

```
原始 patch 序列: [p0, p1, p2, ..., p87]
编码结果:      [TRK_MEL, t0, t1, t2, ..., t87]
```

其中 `ti` 的规则为：

- 非空 patch：输出对应的三进制 patch token
- 空 patch：输出 `EMPTY`

这是一种退化的 pianoroll patch 编码。pitch 信息不再由显式 token 提供，而是由固定槽位隐含表示。

### 训练 (无条件 LM)

```
Input:  [BOS][TS][BPM] [BAR][BEAT][TRK_MEL][mel₀...][TRK_ACC][acc₀...] ... [EOS]
Labels: [BOS][TS][BPM] [BAR][BEAT][TRK_MEL][mel₀...][TRK_ACC][acc₀...] ... [EOS]
```

所有 token 参与 loss，HuggingFace 内部自动 shift。

## 设计原则

1. **model 不碰磁盘** — 输入是 tensor，输出是 tensor
2. **converter 不知道 model** — 接口是原始类型 `(mel_beats, acc_beats, tempo)`
3. **inference 是唯一胶水** — 文件 I/O、tokenizer 调度、结果组装全在这里
4. **tokenizer 是编解码核心** — 通过构造注入共享，不重复创建实例
5. **无条件生成** — 无 schedule、无 mel 注入，模型自由生成整首曲子
6. **退化 patch baseline** — 不做稀疏位置压缩，优先保持表示简单直接

## 模型架构

LLaMA 因果语言模型（768d, 18层, 6头, SwiGLU, RoPE）。

- 数据增强：70% 概率音高平移 Δ ∈ [-5, 5]
- Bucket batch sampler：按序列长度分桶减少 padding
- 有效 batch = 2 × 127 = 254，AdamW, lr=5e-5, fp16
- 推理：temperature + top-k + top-p + repetition penalty
